RodeCaster Virtual Audio Driver (VAD)

This installs a self-built, independent replacement for RØDE's broken official virtual audio driver for the RodeCaster Pro 2.

This installer sets up three things:

  • The HAL audio driver (RodeCasterVirtualAudio.driver) into /Library/Audio/Plug-Ins/HAL/, exposing 5 virtual devices (RVAD System / Game / Music / Virtual A / Virtual B) that macOS apps can select as audio input/output.
  • The VAD app into /Applications -- the control surface for everything: a dashboard, per-channel test tones, live level meters, channel-mapping editor, and daemon controls.
  • The background routing daemon (rodevad-router) as a per-user LaunchAgent for the account you're currently logged in as -- it bridges the 5 virtual devices into the RodeCaster Pro 2's real 10-channel "Main Multitrack" hardware interface.

This will restart coreaudiod (macOS's core audio process) as part of installation, which briefly interrupts all system audio for a moment -- close anything currently playing audio before continuing.

This package is ad-hoc signed (no paid Apple Developer ID), so macOS Gatekeeper may show an "unidentified developer" warning before you can run it -- see the project README for how to proceed past that.
