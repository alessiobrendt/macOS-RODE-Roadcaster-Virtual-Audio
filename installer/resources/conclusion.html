Installed

Next steps:

  1. Open VAD from /Applications (Launchpad, Spotlight, or Finder).
  2. Check the Dashboard tab: it should show the HAL driver installed, the RodeCaster Multitrack device connected (if plugged in over USB), all 5 RVAD virtual devices visible, and the router daemon running.
  3. Optionally enable "Launch VAD at Login" on the Dashboard tab if you want the app itself to open automatically -- the background routing daemon already starts on its own via its LaunchAgent regardless of this toggle.
  4. Use the Channel Test tab to confirm each virtual channel carries audio, and the Channel Mapping tab if audio needs to be routed to different RodeCaster hardware channels than the defaults.

To remove everything this installer set up, see the project README's uninstall instructions (uninstall.sh for the driver, daemon/uninstall-daemon.sh for the routing daemon, and manually removing /Applications/VAD.app).
